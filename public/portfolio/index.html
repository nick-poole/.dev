The Inside Part.

Integrations

Third-party APIs (WMATA, REST Countries), payments (Zeffy), booking (Acuity), and form services (Formspree, EmailJS). Websites that do things, not just say things.

Infrastructure

Domain registration, DNS, SSL, and email security records: SPF, DKIM, DMARC. The layer most developers outsource, handled in-house.

Accessibility

WCAG 2.1 AA and Section 508 validated with WAVE, NVDA, and LambdaTest. Keyboard navigation and screen readers tested by hand, not assumed. This site holds itself to the same standard in public: the conformance statement.

In the Open

Source code public on GitHub. Every project here can be read, not just admired.
